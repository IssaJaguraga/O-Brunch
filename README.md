# O'Brunch

Site vitrine d'un restaurant de brunch, réalisé avec **SvelteKit** pendant ma formation Développeur Web et Web Mobile chez O'clock.

## Fonctionnalités

- Navigation en une seule page (SPA) avec un menu burger
- Carte des brunchs avec ajout et suppression au panier
- Formulaire de réservation (date, créneau, nombre de personnes) avec calcul du total
- Design responsive, pensé mobile first

## Technologies

Svelte • SvelteKit • JavaScript • HTML • CSS • Vite • ESLint • Prettier

## Lancer le projet

```sh
cd o-brunch
npm install
npm run dev
```

Le site est ensuite disponible sur `http://localhost:5173`.
